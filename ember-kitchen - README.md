# Ember Kitchen

A bold editorial restaurant demo with live-fire styling, a scrolling dish ticker, a hover-responsive menu, and responsive reservation and gallery sections.

- Eight languages: English, Spanish, French, German, Portuguese, Arabic, Chinese, and Swahili
- Light and dark themes
- Base64-embedded WebP food imagery with image close-up preview
- Scroll reveals and a Back-to-Top Button
- Fictional demo contact details in Nairobi, Kenya

## Files

- `ember-kitchen - index.html` — complete self-contained demo
- `ember-kitchen - style.css` and `ember-kitchen - script.js` — customization references

The demo’s CSS, JavaScript, and images are already embedded in its HTML file. Replace the fictional restaurant details before using it for a real business.
