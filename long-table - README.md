# The Long Table

A warm, communal restaurant demo with a menu organized by sharing size, a rotated stamp badge, a recipe-card aside, and a tilted photo-wall gallery.

- Eight languages: English, Spanish, French, German, Portuguese, Arabic, Chinese, and Swahili
- Light and dark themes
- All food images are embedded as Base64 WebP
- Image close-up preview, scroll reveals, and a Back-to-Top Button
- Fictional demo contact details in Dar es Salaam, Tanzania

## Files

- `long-table - index.html` — complete self-contained demo
- `long-table - style.css` and `long-table - script.js` — customization references

The demo’s CSS, JavaScript, and images are already embedded in its HTML file. Replace the fictional restaurant details before using it for a real business.
