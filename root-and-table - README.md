# Root & Table

A quiet, minimal restaurant demo with a cookbook-style menu column, scroll-snap gallery, and responsive reservation and dining sections.

- Eight languages: English, Spanish, French, German, Portuguese, Arabic, Chinese, and Swahili
- Light and dark themes
- Base64-embedded WebP food imagery with image close-up preview
- Scroll reveals and a Back-to-Top Button
- Fictional demo contact details in Kigali, Rwanda

## Files

- `root-and-table - index.html` — complete self-contained demo
- `root-and-table - style.css` and `root-and-table - script.js` — customization references

The demo’s CSS, JavaScript, and images are already embedded in its HTML file. Replace the fictional restaurant details before using it for a real business.
