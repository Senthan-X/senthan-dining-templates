# Sunrise Pantry — V5

A bright all-day East African pantry café concept set in Arusha, Tanzania. The page is a single self-contained HTML file with 40-dish searchable menu, 43 embedded WebP images (40 menu photos and 3 dedicated hero/story/gathering photos), an image-led full-screen hero, searchable and filterable menu, dietary labels, full-bleed immersive dish viewer, table-request form, light/dark theme, responsive layouts, scroll reveals, and eight languages (EN, ES, FR, DE, PT, AR/RTL, ZH, SW).

The fictional demo contact is +255 700 555 214. The reservation form confirms locally and does not send data.

Open `sunrise-pantry - index.html` in a browser. No external assets, fonts, or services are required.
