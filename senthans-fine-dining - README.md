# Senthan’s Fine Dining

A multipurpose restaurant demo with three color palettes, light and dark themes, a tabbed menu, a chef-ticket hero, and responsive reservation and gallery sections.

- Eight languages: English, Spanish, French, German, Portuguese, Arabic, Chinese, and Swahili
- Base64-embedded WebP food imagery with image close-up preview
- Scroll reveals and a Back-to-Top Button
- Fictional demo contact details in Kampala, Uganda

## Files

- `senthans-fine-dining - index.html` — complete self-contained demo
- `senthans-fine-dining - style.css` and `senthans-fine-dining - script.js` — customization references

The demo’s CSS, JavaScript, and images are already embedded in its HTML file. Replace the fictional restaurant details before using it for a real business.
