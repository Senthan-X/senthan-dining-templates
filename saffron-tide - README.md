# Saffron Tide

A fictional coastal supper-club template set in Nyali, Mombasa, with an ink, shell and coral palette. It includes a full-screen food hero, sixteen-item categorized menu, editorial coastal story, private dining feature, reservation request interaction, and a split editorial dish preview.

- Eight languages: English, Spanish, French, German, Portuguese, Arabic (RTL), Chinese, and Swahili
- Light and dark themes with system preference and stored selection
- All imagery embedded as Base64 WebP in the standalone HTML
- Responsive layout, scroll reveals, menu filters, accessible dish preview, and Back-to-Top Button
- Fictional demo contact details in Nyali, Mombasa, Kenya

## Files

- `saffron-tide - index.html` — complete self-contained demo
- `saffron-tide - style.css` and `saffron-tide - script.js` — customization references

The standalone demo has no external dependencies. Its reservation form is a front-end interaction and does not submit to a booking service. Replace the fictional restaurant details before using it for a real business.
